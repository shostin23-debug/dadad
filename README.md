Bot de catálogo, pedidos y tickets de soporte para `@ilumistore_bot`.

Este repositorio incluye `render.yaml`. Al crear un Blueprint en Render, elige este repositorio y completa estas variables:

- `BOT_TOKEN`: token nuevo generado en BotFather.
- `ADMIN_CHAT_ID`: `7530261961`
- `PAYPAL_ADDRESS`: `shostin23@gmail.com`
- `ZELLE_RECIPIENT`: `Pshahaha63@gmail.com`

El token nunca debe guardarse en GitHub.

## Funcionamiento

- Catálogo con tres gorras y fotos.
- Precio de $40 cada una.
- Selección de tallas 59FIFTY.
- PayPal, Binance Pay, Zelle y pago en persona.
- Pago en persona solamente para direcciones de New Jersey.
- Ticket obligatorio para coordinar una compra en persona.
- Tickets generales con respuestas entre cliente y administrador.
- Comprobante de pago y aprobación o rechazo del pedido.
